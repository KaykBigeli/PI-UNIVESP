# Sistema TO DO – Organizador de Tarefas 🐍

## Objetivo
O objetivo deste projeto é implementar um organizador de tarefas funcional, totalmente operado pelo terminal, utilizando estruturas de dados como listas ou dicionários, podendo também salvar tarefas em arquivos. O sistema oferece comandos claros e funções específicas para cada operação, garantindo organização e facilidade de manutenção.

## Estrutura e Armazenamento
As tarefas podem ser armazenadas utilizando:
- Listas
- Arquivos `.txt` ou `.json`

## Funcionalidades
- Adicionar tarefa
- Remover tarefa
- Listar tarefas
- Salvar em arquivo

## Como Executar
```bash
python main.py
``
